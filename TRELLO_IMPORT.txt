HOW TO USE THIS FILE
====================
Trello has no markdown/CSV board importer — but pasting multiple lines of
text into a list turns each line into its own card automatically. So:

1. Create a board (e.g. "Rental App Backlog").
2. Create one LIST per sprint below (use the exact sprint name as the list
   name, e.g. "Sprint 1 — Foundation: Auth & Property Setup").
3. Click "Add a card" at the bottom of that list, then paste the whole
   block of lines under that sprint's heading in one go. Trello will turn
   each line into its own card, in order.
4. Repeat for each sprint/list.
5. Optional cleanup in Trello afterward:
   - Create one label per epic (Auth, Properties & Units, Tenants, Leases,
     Payments, Maintenance, Access Control) and label each card using the
     [EPIC] tag already in its title.
   - Open BACKLOG.md and copy the "Acceptance:" line from each story into
     that card's description for full detail.

Each line is formatted as:
[EPIC] US-ID — Story title (priority)
